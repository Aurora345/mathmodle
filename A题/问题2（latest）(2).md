# 1. 先说明问题2的数据特点

题目明确指出：

\[

6. 赛题没有解释 `NEWSTRUCTURE` 的具体物理含义，因此本文只把它作为数据中的类别标记，**不把它解释成某种已知的电芯结构差异**；
7. 上述40块电池只对应6种不同的 $C_1,Q_1,C_2$ 参数组合。这里“6”表示参数组合数，而不是整道题只有6种策略；完整策略总数始终是9种。

用于：

## 2.2 为什么选择Kruskal-Wallis

每个策略只有少量电池，而且各策略样本数不完全相等，估计寿命也不应提前假定严格服从正态分布。

所以主检验采用：

\[
\boxed{\text{Kruskal-Wallis秩和检验}}
\]

而不是直接使用普通单因素ANOVA。

Kruskal-Wallis由Kruskal和Wallis提出，用于比较多个独立样本总体位置是否相同。[1]

---

## 2.3 Kruskal-Wallis统计量的来源

设共有 \(G\) 个策略，第 \(g\) 个策略有 \(n_g\) 块电池：

\[
N=\sum_{g=1}^{G}n_g
\]

把全部 \(N\) 个寿命：

\[
\hat L_1,\hat L_2,\ldots,\hat L_N
\]

混合后统一排序，得到秩：

\[
1,2,\ldots,N
\]

若出现相同寿命，则赋平均秩。

令第 \(g\) 个策略的秩和为：

\[
R_g=\sum_{i\in g}r_i
\]

则平均秩为：

\[
\bar R_g=\frac{R_g}{n_g}
\]

在原假设

\[
H_0:
\text{各策略寿命来自相同总体}
\]

成立时，所有组理论平均秩都应接近全体平均秩：

\[
\bar R=\frac{N+1}{2}
\]

因此可以用各组平均秩偏离总体平均秩的程度衡量组间差异。

经过标准化后得到：

\[
\boxed{
H=
\frac{12}{N(N+1)}
\sum_{g=1}^{G}
\frac{R_g^2}{n_g}
-
3(N+1)
}
\]

**【文献公式 [1]：Kruskal & Wallis, 1952】**

也可以理解为：

> \(H\) 越大，说明各策略的平均秩分离越明显，即寿命分布差异越明显。

---

## 2.4 并列秩修正

寿命估计或策略重复可能导致并列秩。

如果某一组并列值共有 \(t_j\) 个，则并列修正系数为：

\[
\boxed{
C=
1-
\frac{\sum_j(t_j^3-t_j)}
{N^3-N}
}
\]

修正后的统计量：

\[
\boxed{
H_c=\frac{H}{C}
}
\]

**【文献公式 [1]】**

实际程序直接使用包含tie correction的实现。

---

## 2.5 小样本下不用只依赖渐近卡方近似

理论上，在样本量足够大时：

\[
H_c\sim\chi^2_{G-1}
\]

但本题每个策略只有少量电池，因此除了常规Kruskal-Wallis \(p\) 值外，再做策略标签置换。

保持每个策略的样本数量不变，随机打乱策略标签 \(B\) 次，例如：

\[
B=100000
\]

每次计算：

\[
H^{(b)}
\]

则经验置换 \(p\) 值为：

\[
\boxed{
p_{\mathrm{perm}}
=
\frac{
1+\sum_{b=1}^{B}
I(H^{(b)}\ge H_{\mathrm{obs}})
}
{B+1}
}
\]

**【本文实现】**

这样做的目的不是再加一个新模型，而是检查：

> **小样本情况下，Kruskal-Wallis显著性结论是否仍然稳定。**

---

## 2.6 效应量

只报告 \(p\) 值不够，还应该报告差异有多大。

本文采用Kruskal-Wallis对应的秩效应量：

\[
\boxed{
\eta_H^2
=
\frac{H-G+1}{N-G}
}
\]

**【文献公式 [4]：Tomczak & Tomczak, 2014】**

其中：

- \(H\)：Kruskal-Wallis统计量；
- \(G\)：策略数量；
- \(N\)：总电池数。

这里明确写清楚使用的是：

\[
\eta_H^2
\]

避免与文献中其他不同定义的 \(\varepsilon^2\) 混淆。

---

## 2.7 总体显著以后再做Dunn两两比较

如果Kruskal-Wallis总体检验显著，再判断具体哪些策略之间存在差异。

设策略 \(g,h\) 的平均秩分别为：

\[
\bar R_g,\quad \bar R_h
\]

则Dunn统计量为：

\[
\boxed{
Z_{gh}
=
\frac{\bar R_g-\bar R_h}
{
\sqrt{
S_R^2
\left(
\frac1{n_g}+\frac1{n_h}
\right)
}
}
}
\]

其中考虑并列秩后的秩方差为：

\[
\boxed{
S_R^2
=
\frac{N(N+1)}{12}
-
\frac{
\sum_j(t_j^3-t_j)
}{
12(N-1)
}
}
\]

**【文献公式 [2]：Dunn, 1964】**

---

## 2.8 Holm多重比较校正

如果有 \(m\) 个两两比较，将原始 \(p\) 值由小到大排列：

\[
p_{(1)}\le p_{(2)}\le\cdots\le p_{(m)}
\]

Holm方法依次比较：

\[
\boxed{
p_{(j)}
\le
\frac{\alpha}{m-j+1}
}
\]

**【文献规则 [3]：Holm, 1979】**

一旦某一步不能拒绝，则后续更大的 \(p\) 值均不再拒绝。

这样比直接使用未校正的两两检验更能控制多重比较产生的假阳性。

1. **主分析：** 9种策略的 $r_i^{stable}$；
2. **辅助分析：** 9种策略的 $\hat L_i^{base}$。

两套分析都报告：

# 3. 第2小问：分析稳定退化速率与基准EOL同充电参数的关系

这一问分两层：

1. 先分析原始三个参数与**稳定退化速率**的关系；
2. 再将问题1基准EOL作为辅助响应，检查长期外推方向是否一致；
3. 根据数据结构把三个参数重新表示成“倍率在SOC区间上的分配”。


# 3.1 原始参数关系：Spearman相关

原始参数 $C_1,Q_1,C_2$ 与两个响应都做策略级Spearman描述：

### 主响应

\[
C_1-r^{stable},\qquad
Q_1-r^{stable},\qquad
C_2-r^{stable}.
\]

### 辅助响应

\[
C_1-\hat L^{base},\qquad
Q_1-\hat L^{base},\qquad
C_2-\hat L^{base}.
\]

由于参数取值离散，并存在相同策略参数，使用带平均秩处理的Spearman相关，而不使用无并列秩时的简化公式。

如果某一参数同时表现为：

\[
\rho(parameter,r^{stable})>0
\]

和：

\[
\rho(parameter,\hat L^{base})<0,
\]

则两套响应的物理方向一致：倍率更大对应更快稳定退化、同时对应更短基准EOL。

这里Spearman只用于描述单参数单调关系，不用于替代后面的 $A,D$ 联合模型，也不作因果解释。

# 3.2 VIF共线性诊断及公式推导

共线性诊断分成两层。第一层对原始参数 \(C_1,Q_1,C_2\) 计算VIF，用于说明原始设计耦合及重参数化的必要性；第二层对正式主模型中的 \(A,D\) 再计算VIF，用于判断重参数化后的模型是否仍有严重共线性。对每一个参数 \(X_j\)，用其他参数回归它：

\[
X_j
=
a_0+
\sum_{k\ne j}a_kX_k+
e
\]

得到决定系数：

\[
R_j^2
\]

在线性回归中，\(\hat\beta_j\) 的方差可写为：

\[
\mathrm{Var}(\hat\beta_j)
=
\frac{\sigma^2}
{
S_{jj}(1-R_j^2)
}
\]

其中：

\[
S_{jj}=\sum_i(X_{ij}-\bar X_j)^2
\]

如果 \(X_j\) 与其他变量完全正交，则：

\[
R_j^2=0
\]

此时：

\[
\mathrm{Var}_0(\hat\beta_j)
=
\frac{\sigma^2}{S_{jj}}
\]

两者相除：

\[
\frac{
\mathrm{Var}(\hat\beta_j)
}{
\mathrm{Var}_0(\hat\beta_j)
}
=
\frac1{1-R_j^2}
\]

因此定义：

\[
\boxed{
VIF_j=\frac1{1-R_j^2}
}
\]

**【本文根据OLS方差公式推导】**

本题中VIF只作为：

> **参数结构诊断指标**

不机械使用“VIF大于5或10就必须删变量”的固定规则。

正式运行时，分别报告原始参数 \(C_1,Q_1,C_2\) 与重参数化后 \(A,D\) 的VIF。这里 \(A,D\) 的相关系数和VIF只基于不同的策略级参数位置计算，不把同一policy下的重复电池展开成重复坐标，否则会人为改变各策略位置在共线性诊断中的权重。

\[
I_1=C_1Q_N
\]

\[
t=\frac{\Delta Q}{I}
\]

\[

注意：即使观察到近等时，也不能仅据此反推出实验人员一定按某个固定时间设计策略；若要讨论原始实验设计意图，需要另外引用数据来源文献。

# 3.6 构造总体倍率水平 \(A\)

所以：

因此：

# 3.7 构造低SOC和高SOC倍率暴露

设SOC分界为：

s_0

定义低SOC区间平均倍率：

\boxed{
E_{L,i}(s_0)

\frac1{s_0}
\int_0^{s_0}C_i(s)\,ds
}
\]

定义中高SOC区间平均倍率：

\[
\boxed{
E_{H,i}(s_0)
=
\frac1{0.8-s_0}
\int_{s_0}^{0.8}C_i(s)\,ds

**【本文构造】**

## 低SOC暴露的闭式表达

低SOC区间中，\(C_1\) 实际覆盖长度为：

\[
\min(q_i,s_0)

剩余部分由 \(C_2\) 覆盖。

所以：

\[
\boxed{
E_{L,i}
=
\frac{

C_{2i}[s_0-\min(q_i,s_0)]
}{s_0}
}
\]

**【本文推导】**

---

## 高SOC暴露的闭式表达

当：

\[
q_i>s_0

时，\(C_1\) 在高SOC区间中仍持续：

\[
q_i-s_0
\]

因此一般形式为：

\[
\boxed{
E_{H,i}
=
\frac{
C_{1i}\max(q_i-s_0,0)
+
C_{2i}[0.8-\max(q_i,s_0)]
}{
0.8-s_0
}
}
\]

**【本文推导】**

# 3.8 构造“高SOC相对低SOC倍率差” \(D\)

定义：

\[
\boxed{
D_i
=
E_{H,i}-E_{L,i}
}
\]

**【本文构造】**

解释：

- \(D_i>0\)：中高SOC区间平均倍率高于低SOC；
- \(D_i<0\)：高倍率更多布置在低SOC，后期主动降低倍率；
- \(D_i\approx0\)：前后两个SOC区间倍率接近。

所以：

\[
\boxed{
A=\text{总体倍率水平},
\qquad
D=\text{倍率在SOC上的分配方向}
}
\]

比单独解释 \(C_1,Q_1,C_2\) 更贴近题目物理含义。

# 4. 第3小问：检验策略参数是否具有显著影响，并分析影响程度

> **样本口径再次强调：** 第1小问用全部9种策略；9种中有8种三参数完整，但第3、4小问的主参数效应模型仍优先使用 `dataset_id=3` 的6个NEWSTRUCTURE策略参数位置。这样做是为了让dataset与类别标签保持一致、降低混杂，而不是因为另外两个策略“参数不完整”。其他参数完整策略仅用于敏感性/对照，不把不同dataset和类别不加区分地混成一个“纯参数效应”。



## 4.1 先解决“重复电池不是新的参数组合”的问题

参数效应主分析不直接把同一策略下的重复电池当成新的参数位置。

对每种策略 $g$，先计算：

\[
\boxed{
R_g
=
\operatorname{Median}
\{r_i^{stable}:i\in g\}
}
\]

作为**主要响应**，以及：

\[
\boxed{
L_g
=
\operatorname{Median}
\{\hat L_i^{base}:i\in g\}
}
\]

作为辅助EOL响应。

因此6种NEWSTRUCTURE策略仍只对应6个不同的参数位置：

\[
(A_g,D_g,R_g,L_g).
\]

同策略内部多块电池用于估计该策略结果的不确定性，而不是人为增加参数组合数量。

---

# 4.2 主响应与辅助响应

### 主响应：稳定退化速率

由于：

\[
r_i^{stable}=-\hat k_{SOH,i}^{stable}>0,
\]

数值越大表示稳定阶段衰减越快。主模型直接使用：

\[
\boxed{Y_g^{main}=R_g}
\]

不需要对数变换。

### 辅助响应：基准EOL

基准EOL可能明显右偏，因此只对辅助寿命模型检查原尺度/对数尺度：

\[
Y_g^{EOL}
=
\mathcal G(L_g),
\]

其中：

\[
\mathcal G(x)
=
\begin{cases}
x,&\text{原尺度诊断良好},\\
\log x,&\text{明显右偏/异方差}.
\end{cases}
\]

新版证据优先级明确为：

\[
\boxed{
A,D\rightarrow r^{stable}
\quad\text{优先于}\quad
A,D\rightarrow \hat L^{base}
}
\]

原因是前者直接来自实际观测稳定下降段，后者还叠加了远期函数形式不确定性。

---

# 4.3 标准化

仍对 $A,D$ 标准化：

\[
Z_{A,g}
=
\frac{A_g-\bar A}{s_A},
\qquad
Z_{D,g}
=
\frac{D_g-\bar D}{s_D}.
\]

这样两个系数可比较相对影响强弱。

---

# 4.4 主参数效应模型：解释稳定退化速度

正式主模型改为：

\[
\boxed{
R_g
=
\gamma_0
+
\gamma_A Z_{A,g}
+
\gamma_D Z_{D,g}
+
e_g
}
\]

其中：

- $\gamma_A>0$：总体倍率越高，与更快的稳定SOH衰减相关；
- $\gamma_D>0$：倍率更多分配到中高SOC时，与更快稳定衰减相关；
- 若系数为负，则按实际方向解释，不预设结论。

辅助EOL模型为：

\[
\boxed{
Y_g^{EOL}
=
\beta_0
+
\beta_A Z_{A,g}
+
\beta_D Z_{D,g}
+
\varepsilon_g
}
\]

对于寿命响应，若倍率更高对应寿命更短，通常会表现为负系数；因此主响应和辅助响应在符号上可能相反，但物理方向可以一致：

\[
\gamma>0
\Longleftrightarrow
\beta<0.
\]

# 4.5 OLS估计与小样本限制

两套模型都先用OLS。矩阵形式：

\[
\mathbf y=\mathbf X\boldsymbol\theta+\boldsymbol\varepsilon,
\qquad
\hat{\boldsymbol\theta}
=
(\mathbf X^T\mathbf X)^{-1}\mathbf X^T\mathbf y.
\]

真正不同的参数位置只有6个，而模型含截距、$A$、$D$，残差自由度只有3。因此不能只看一个很高的训练 $R^2$ 就宣称参数作用已经被证明。

每套模型都至少报告：

- $R^2$；
- 调整 $R^2$；
- 精确置换 $p$；
- LOPO预测误差；
- 留一策略系数方向；
- 分层Bootstrap系数区间。

---

# 4.6 精确置换检验：主响应和EOL响应都做720种全排列

保持：

\[
(A_g,D_g)
\]

不变，把6个策略的响应重新排列。由于只有6个参数位置：

\[
6!=720.
\]

对稳定退化速率模型计算：

\[
\boxed{
p_{exact}^{rate}
=
\frac{\#\{R_{b,rate}^2\ge R_{obs,rate}^2\}}{720}
}
\]

对辅助EOL模型计算：

\[
\boxed{
p_{exact}^{EOL}
=
\frac{\#\{R_{b,EOL}^2\ge R_{obs,EOL}^2\}}{720}
}
\]

不把 $p=0.05$ 当成机械分界；正式运行时同时报告精确分数、$p$值及其百分比表示。

# 4.7 Leave-One-Policy-Out：真正检查“参数权重是否稳定”

这一部分采用用户提出的“每次留一组、比较模型参数”的思想，但应用在真正存在全局回归权重的Q2模型上。

对6种参数完整策略做6折LOPO：

1. 留出策略 $g$；
2. 用其余5个策略拟合主模型；
3. 保存
   \[
   \gamma_A^{(-g)},\quad\gamma_D^{(-g)};
   \]
4. 预测被留出的 $R_g$；
5. 对辅助EOL模型同样保存
   \[
   \beta_A^{(-g)},\quad\beta_D^{(-g)}.
   \]

重点报告：

\[
\boxed{
\text{系数同号折数}
}
\]

\[
\boxed{
[\min\gamma_A,\max\gamma_A],
\quad
[\min\gamma_D,\max\gamma_D]
}
\]

以及LOPO MAE/RMSE和Spearman。

这里更准确的术语是：

> **留一策略系数稳健性/参数方向稳定性**

而不是“参数收敛”。

如果6折中系数方向频繁翻转，即使训练 $R^2$ 很高，也说明小样本下参数解释不稳定。

# 4.8 分层Bootstrap

仍按policy内部重采样，不能把6种真实参数位置变成更多新的参数位置。

第 $b$ 次Bootstrap重新计算各策略：

\[
R_g^{(b)},\qquad L_g^{(b)}
\]

并分别拟合：

\[
\gamma_A^{(b)},\gamma_D^{(b)}
\]

以及：

\[
\beta_A^{(b)},\beta_D^{(b)}.
\]

报告95%经验区间。

Bootstrap主要衡量同一策略内部重复电池带来的不确定性；它不能弥补“参数空间只有6个位置”的根本限制。

辅助EOL模型的 $|\beta_A|,|\beta_D|$ 只用于检查方向是否一致，不反过来主导结论。

# 4.11 OLS不稳定时才使用Ridge

如果发现：

- OLS系数对留出一个策略非常敏感；
- \(A,D\) 仍有明显共线性；
- LOPO预测误差很大；

再引入Ridge。

Ridge目标函数：

\[
\boxed{
J(\boldsymbol\beta)
=
\|\mathbf y-\mathbf X\boldsymbol\beta\|_2^2
+
\lambda\|\boldsymbol\beta\|_2^2
}
\]

**【文献公式 [5]：Hoerl & Kennard, 1970】**

---

## Ridge闭式解推导

展开并求导：

\[
\frac{\partial J}
{\partial\boldsymbol\beta}
=
-2\mathbf X^T\mathbf y
+
2\mathbf X^T\mathbf X\boldsymbol\beta
+
2\lambda\boldsymbol\beta
\]

令：

\[
\frac{\partial J}{\partial\boldsymbol\beta}=0
\]

得到：

\[
(\mathbf X^T\mathbf X+\lambda\mathbf I)
\boldsymbol\beta
=
\mathbf X^T\mathbf y
\]

因此：

\[
\boxed{
\hat{\boldsymbol\beta}_{Ridge}
=
(\mathbf X^T\mathbf X+\lambda\mathbf I)^{-1}
\mathbf X^T\mathbf y
}
\]

**【文献公式 [5]】**

Ridge通过：

\[
\lambda\mathbf I
\]

降低非正交/共线性条件下系数估计的不稳定性。[5]

---

# 4.12 Leave-One-Policy-Out选择Ridge参数

如果使用Ridge，不使用随机K折。

因为随机拆分同一policy会让训练集提前看到几乎相同的策略参数。

设共有：

\[
G
\]

种策略。

第 \(g\) 次：

1. 完整留下第 \(g\) 个策略；
2. 用剩余 \(G-1\) 个策略拟合；
3. 预测留下策略。

定义：

\[
\boxed{
RMSE_{LOPO}(\lambda)
=
\sqrt{
\frac1G
\sum_{g=1}^{G}
[
Y_g-\hat Y_g^{(-g)}(\lambda)
]^2
}
}
\]

选择：

\[
\boxed{
\lambda^*
=
\arg\min_{\lambda}
RMSE_{LOPO}(\lambda)
}
\]

**【本文针对策略重复结构设计的验证方法】**

只有当Ridge的LOPO误差明显优于OLS时，才把Ridge作为最终稳定模型。

否则保留更简单的OLS。

特别注意：

> **这里LOPO的主要作用是检验“去掉一个策略以后，系数方向和模型关系是否仍然稳定”，并辅助OLS/Ridge取舍，而不是把LOPO误差包装成最终独立预测准确率。**

如果同一套LOPO结果既用于选择 \(\lambda\) 或决定OLS/Ridge，又直接把其中最低的RMSE当作最终泛化误差，会存在模型选择偏差。考虑到本题真正只有6个策略参数位置，继续做更深层嵌套会使每层训练点更少，因此问题2不把预测精度作为主要结论，而把LOPO定位为**小样本策略级稳定性/压力测试**；参数效应的结论仍需结合效应方向、精确置换和分层Bootstrap共同判断。

由定义：

\[

所以：

\[
\int_0^{s_0}C(s)\,ds

同理：

\[

(0.8-s_0)E_H
\]

因此总体倍率：

\[

=
\frac1{0.8}
\int_0^{0.8}C(s)\,ds
\]

可以写成：

\[
\boxed{

=
\frac{
s_0E_L+
(0.8-s_0)E_H
}{0.8}
}
\]

又因为：

\[
\boxed{

}

所以：

\[

\]

代入：

\[

=
s_0E_L
+
(0.8-s_0)(E_L+D)
\]

整理：

\[
0.8A
=
0.8E_L
+
(0.8-s_0)D
\]

因此：

\[
\boxed{
E_L
=
A-
\frac{0.8-s_0}{0.8}D
}
\]

进一步：

\[
\boxed{
E_H
=

\frac{s_0}{0.8}D
}

**【本文推导】**

所以：

这保证第3问和第4问逻辑一致，而不是两套彼此矛盾的模型。

且方向一致，才能说：

> **中高SOC区间的高倍率暴露与寿命下降表现出更强关联。**

如果结论随 \(s_0\) 剧烈变化，则应如实说明SOC区间效应证据不足。

---

# 5.4 为什么这个方法比只比较 \(C_1,C_2\) 更合理

因为：

\[
C_1
\]

到底作用到多少SOC，由：

\[
Q_1
\]

决定。

例如同样：

\[
C_1=5C
\]

若只持续到20% SOC，与持续到70% SOC，其电池承受的高倍率区间完全不同。

所以：

\[
\boxed{
\text{倍率大小}
+
\text{作用SOC范围}
}
\]

必须联合考虑。

这正是：

\[
C(s),\quad E_L,\quad E_H
\]

的意义。

---

# 6. 第5小问：结合统计结果讨论可能机制及局限性

这一问不再添加新的复杂预测模型。

使用：

\[
SOH,\quad IR,\quad Tavg
\]

对前4问统计结果进行物理解释。

---

# 6.1 机制解释以观测退化指标为主

修订后的问题1基准寿命模型只使用SOH，不把IR和温度正式纳入寿命预测；SOH+IR+温度+充电时间的多维预测统一放到问题3。

因此问题2第5问仍然优先使用**直接观测得到的退化指标**来解释机制，而不是等问题3完成后再用问题3预测寿命反向解释问题2。这里的IR、Tavg以及必要时使用的ChargeTime，全部来自 `cycle_train.csv` 的逐循环实测值，并在前150圈或相应可见区间内计算水平、趋势或策略级统计量；**不使用** `battery_summary.csv` 中的 `mean_IR`、`mean_Tavg`、`mean_chargetime`，因为这三个量是完整寿命区间平均值，只在问题3最终寿命预测完成后作为真实汇总对照。主要分析：

\[
\boxed{
E_H\rightarrow k_{IR}
}
\]

\[
\boxed{
E_H\rightarrow Tavg
}
\]

以及：

\[
\boxed{
k_{IR},Tavg
\leftrightarrow
k_{SOH}^{obs}
}
\]

这里：

\[
k_{SOH}^{obs}
\]

来自真实前150圈SOH变化，不依赖EOL外推。

正式运行时，在策略级比较平均倍率$A$与内阻增长斜率、**由前150圈逐循环Tavg计算的策略级平均温度**以及稳定退化速率 $r^{stable}$ 之间的Spearman相关。这里的小样本相关只用于提供描述性机制线索，不据此识别中高SOC暴露通过何种通道作用。


问题2在这里可以先回答“充电策略是否与逐循环IR/温度/ChargeTime及SOH退化存在伴随关系”，并为问题3提供Policy或$A,D$等策略表示；但**不在问题2建立用于还原完整寿命三个均值的正式预测模型**。真正的实时映射

\[
X_{i,n}=f_X(SOH_{i,n},\text{Policy}_i),\qquad X\in\{IR,Tavg,ChargeTime\}
\]

统一放到问题3中，用40块非测试电池的逐循环数据拟合和留一电池验证。这样Q2负责解释关系，Q3负责把关系用于寿命预测的辅助准确性检验。

---

# 6.2 内阻趋势

直接复用问题1已经建立的稳健趋势指标：

\[
k_{IR}
\]

分析：

\[
E_L,\ E_H,\ D
\]

与：

\[
k_{IR}
\]

之间的关系。

若中高SOC高倍率策略同时表现为：

\[
E_H\uparrow
\]

\[
k_{IR}\uparrow
\]

\[
k_{SOH}^{obs}\text{更负}
\]

则可以写出相应的方向一致性解释。正式运行后根据 $E_H$ 与 $k_{IR}$ 的相关方向、效应大小和不确定性判断该通道是否获得支持；若证据不足，只保留“中高SOC倍率暴露与寿命下降的统计关联”，不把内阻增长写成已验证中介机制。

一般情况下只有观察到三者方向一致，才可以写：

> **中高SOC较高倍率与更快的内阻增长及SOH下降方向一致。**

不能写：

> “已经证明高SOC倍率通过内阻增长导致寿命下降。”

---

# 6.3 温度

比较策略级：

\[
Tavg
\]

与：

\[
E_L,\quad E_H,\quad D
\]

的变化关系。

如果：

\[
E_H\uparrow
\]

同时：

\[
Tavg\uparrow
\]

且：

\[
k_{SOH}^{obs}\text{更负}
\]

则可以讨论：

> 较高倍率带来的更大电流可能增加热负荷，并与更快衰减伴随出现。

正式运行后比较 $E_H$、平均倍率$A$ 与**前150圈逐循环Tavg得到的策略级温度统计量**之间的关系，再判断热效应更支持“总体倍率”还是SOC位置相关的解释。无论结果如何，温度关联都不能替代$D$或$E_H$本身的统计证据。Gao等[10]的实验表明，充电电流和充电截止状态等充电应力会影响容量衰减和内阻增长。

---

# 6.4 机制解释必须保持克制

相关研究表明：

- 较高充电电流可能增加极化和老化应力；
- 不同充电状态/截止状态对老化可能产生不同影响；
- 内阻增长和容量衰减均可作为老化表征之一。[10]

但是，LiFePO\(_4\)体系中并不是所有快充方案都必然产生更严重衰减。

Anseán等[9]研究LiFePO\(_4\)多阶段快充时发现，其设计的快充策略与标准充电可能产生相近的循环老化效果。

所以本题最终应该写：

> **“统计结果与某些可能的电化学老化机制一致，但快充倍率、SOC区间和老化之间的关系具有明显的电池体系与协议依赖性。”**

不要写：

> “倍率越高一定越伤电池。”

# 8. 为什么这套方案比直接使用Mixed Effects + Elastic Net + GP更合适

## 8.1 当前真正不同的参数组合很少

虽然有49块电池，但充电参数组合只有少数几种。

复杂模型并不能凭空创造新的实验设计信息。

---

## 8.2 题目的核心不是预测，而是解释

问题2需要回答：

\[
C_1,Q_1,C_2
\]

以及：

\[
SOC\text{区间}
\]

如何与寿命衰减关联。

因此可解释的参数化比黑箱预测更重要。

---

## 8.3 Ridge只在数据需要时使用

Ridge确实适合非正交变量。[5]

但如果：

\[
A,D
\]

重参数化以后OLS已经稳定，则没有必要为了“高级”强行使用Ridge。

---

## 8.4 Gaussian Process暂时不作为问题2主模型

真正不同的参数组合太少。

在少数离散参数组合之间画连续响应面，会让大量未实验区域主要依赖模型插值。

因此GP更适合留到问题4：

> 当确实需要在已有策略合理邻域内进行连续优化时，再判断是否需要代理模型。

---

## 8.5 Mixed Effects不是错误，而是当前不是必须

如果直接分析所有SOH循环轨迹，同一电池的重复观测确实存在相关性，混合效应模型是合理工具。

但问题1已经提取：

\[
\hat L,\quad
\hat k_{SOH}
\]

问题2主要研究策略参数效应。

所以没有必要再额外建立一整套轨迹Mixed Effects模型，除非后续发现单一SOH斜率不能概括实际退化轨迹。

---

只能写：

不能写：

它们的主要作用是：

仍然需要VIF/条件数和LOPO稳定性检查。

\]

第4问只是把第3问展开为更直接的SOC区间解释。

# 13. 正式计算后需要填写的结果（放在问题2的文件夹里，命名好）

新版所有显著性、误差和模型稳定性结果都同时记录“原始量纲 + 百分比/比例”，便于论文直观呈现。

## 第1小问

主分析（稳定退化速率）与辅助分析（基准EOL）分别记录：

- Kruskal-Wallis $H$；
- 渐近 $p$ 值；
- 标签置换 $p$ 值，并同时写成百分比；
- $\eta_H^2$；
- Dunn-Holm两两比较。

正式运行时，九策略总体差异采用 $B=100000$ 次随机标签置换，并按

\[
p_{\mathrm{MC}}=\frac{1+\#\{H_b\ge H_{\mathrm{obs}}\}}{B+1}
\]

同时报告超越次数、$B$、$p$ 值及 $100p\%$。其中 $720=6!$ 仅用于六个不同参数位置的 $A,D$ 回归精确全排列检验，不得与九策略随机置换混用。

## 第2小问

- $C_1,Q_1,C_2$ 与 $r^{stable}$ 的Spearman；
- $C_1,Q_1,C_2$ 与 $\hat L^{base}$ 的Spearman作为辅助；
- 原始参数与 $A,D$ 的VIF；
- 各策略 $T_{0-80}^{theo}$；
- $A,D,E_L,E_H$。

## 第3小问

**主模型：**

\[
R_g=\gamma_0+\gamma_AZ_A+\gamma_DZ_D+e
\]

记录：

- $\gamma_A,\gamma_D$；
- $R^2$/调整 $R^2$；
- 720种完全枚举置换 $p_{exact}^{rate}$；
- LOPO六折中两系数同号折数、最小/最大值；
- LOPO MAE/RMSE；
- policy内分层Bootstrap 95%区间。

**辅助EOL模型：** 同样记录 $\beta_A,\beta_D$ 和 $p_{exact}^{EOL}$，但只用于方向一致性。

## 第4小问

- 不同 $s_0$ 下 $E_L,E_H$ 对稳定退化速率的回归结果；
- 辅助EOL结果；
- SOC分界敏感性。

# 14. 最终执行流程

1. 承接问题1最终稳定起点 $n_0^*$、每块电池稳定退化速率 $r_i^{stable}$ 和基准EOL $\hat L_i^{base}$；
2. 9种策略首先比较 $r^{stable}$ 分布，作为直接观测的主要策略差异证据；
3. 同样比较基准EOL分布，作为辅助寿命证据；
4. 两套响应分别做Kruskal-Wallis、标签置换、效应量；总体显著后再做Dunn-Holm；
5. 对参数完整样本分别画 $C_1,Q_1,C_2-r^{stable}$ 与 $C_1,Q_1,C_2-\hat L$；
6. 做VIF及参数结构诊断；
7. 根据C-rate定义计算 $T_{0-80}^{theo}$；
8. 将策略转换成 $C(s)$，计算 $A,E_L,E_H,D$；
9. 对6个NEWSTRUCTURE参数位置，以策略稳定退化速率中位数为主响应拟合 $A,D$ OLS；
10. 对主响应完整枚举720种排列；
11. 做6折Leave-One-Policy-Out，保存每折 $\gamma_A,\gamma_D$ 并检查方向稳定性；
12. 按policy做5000次分层Bootstrap；
13. 以基准EOL重复一套辅助回归和置换，检查方向一致性；
14. OLS明显不稳定时才引入Ridge，并用LOPO选 $\lambda$；
15. 对 $s_0=40\%,45\%,50\%,55\%,60\%$ 做SOC区间敏感性；
16. 用逐循环SOH/IR/Tavg/ChargeTime做机制辅助分析，不使用完整寿命summary均值；
17. 将Policy及 $A,D,E_L,E_H$ 交给问题3作为候选策略信息；
18. 最终明确区分“观测稳定退化证据”和“远期EOL派生证据”。
